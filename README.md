# LOSCA - local-open-single-cell-analysis
An open-source privacy-by-design website for analyzing count matrices from scRNA-seq experiments and visualizing results.

### Description
In the medical field, data is highly sensitive and requires computer science skills to analyze. These barriers can slow down new life-saving discoveries. To address this challenge, I developed an intuitive, privacy-by-design web application specifically for preprocessing count matrices from single-cell RNA-seq experiments and visualizing the results. This tool processes all information locally, directly within the user's browser. By ensuring that sensitive experimental data are never uploaded to external servers, the application guarantees strict adherence to data privacy policies while providing researchers with an accessible, secure, and efficient analysis environment.
